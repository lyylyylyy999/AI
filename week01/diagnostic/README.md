# Python 基础诊断：学生成绩摘要

## 目的

这不是考试。它用于判断后续应该在哪些 Python 知识上放慢或加速。

建议用时：30–45 分钟。请先不要使用 pandas，也不要让 AI 直接生成完整答案。

## 任务

新建 `score_summary.py`，读取本目录 `data/students.csv`，输出：

1. 学生总人数。
2. `score` 的平均分，保留两位小数。
3. 最高分学生的姓名和分数。
4. 及格人数与及格率，60 分及以上算及格。
5. 每个专业 `major` 的平均分。

期望输出内容与下面相同；排版可以不同：

```text
学生人数: 8
平均分: 74.50
最高分: 92.0 (赵六)
及格人数: 6
及格率: 75.00%
各专业平均分:
  应用统计: 82.33
  经济统计: 68.00
  数据科学: 72.50
```

## 要求

- 使用 Python 标准库读取 CSV。
- 至少自己定义 2 个函数。
- 正确把分数字符串转换成数字。
- 不要把最终结果直接写死在代码里。
- 遇到问题时，保留报错信息并记录你尝试过什么。

## 可选挑战

完成基础任务后，再任选一项：

- 当文件不存在时，输出友好错误信息。
- 通过命令行参数传入 CSV 文件路径。
- 为一个计算函数添加类型标注。

