# 第 3 周学习看板：DeepSeek 客户端与模型响应边界

## 本周目标

在不进行真实付费调用的前提下，用 MockTransport 完成 DeepSeek V4 请求、HTTP 响应结构提取、模型 JSON 解析，并接入第 2 周的数据校验。

## 容量

- 计划 3 个新知识任务，每个 60–90 分钟。
- 预留修正、复盘和质量门时间，总量控制在 6–9 小时。
- 不组装最终 CLI；CLI 和完整错误矩阵留到第 4 周。

## 看板

| 卡片 | 目标 | 预计时间 | 状态 | 验收证据 |
|---|---|---:|---|---|
| W3-01 | DeepSeek V4 最小同步客户端 | 60–90 分钟 | 已准备 | 假 Key、V4 请求契约、Mock 401 与 timeout |
| W3-02 | 提取 `choices[0].message.content` | 60–90 分钟 | 待开始 | 正常响应及响应结构缺失测试 |
| W3-03 | 解析模型 JSON 并调用业务校验 | 60–90 分钟 | 待开始 | 非法 JSON、code fence、字段错误测试 |
| W3-04 | 周复盘与质量门 | 45–60 分钟 | 待开始 | 独立修改、项目讲解和周评分 |

## 安全边界

- 自动化测试只使用假 Key 与 MockTransport。
- 不读取或打印 `.env`、真实 Key、Authorization Header。
- 本周不进行真实 DeepSeek 请求，不产生 API 费用。
