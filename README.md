## 学习规则

1. 每个任务先独立完成，再请求代码审查。
2. 不要求一次写对，但需要记录错误信息和自己的判断。
3. 每次提交保持范围小，并写清楚提交信息。
4. 项目必须逐步补齐 README、类型标注、异常处理和测试。
5. 每周新知识控制在 2–3 个主要任务，总学习量按 6–9 小时安排；阶段剩余任务不能全部塞入单周。
