# LLM 应用开发学习仓库

目标：在 24 周内完成从 Python 基础到可部署的大模型应用，并形成实习作品集。

## 当前阶段

- 阶段：第 1 阶段——Python 工程基础
- 当前任务：[第 1 周诊断练习](week01/diagnostic/README.md)
- 学习节奏：每周 2–3 次，每次暂按约 3 小时安排

## 学习规则

1. 每个任务先独立完成，再请求代码审查。
2. 不要求一次写对，但需要记录错误信息和自己的判断。
3. 每次提交保持范围小，并写清楚提交信息。
4. 项目必须逐步补齐 README、类型标注、异常处理和测试。
