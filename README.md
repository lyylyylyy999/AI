## 学习规则

1. 每个任务先独立完成，再请求代码审查。
2. 不要求一次写对，但需要记录错误信息和自己的判断。
3. 每次提交保持范围小，并写清楚提交信息。
4. 项目必须逐步补齐 README、类型标注、异常处理和测试。

## 参考答案更新规则

- 小练习过程中不追改参考答案。
- 每个阶段验收通过后，校准参考实现并更新阅读指南。
- 参考答案代表当前阶段的推荐实现，旧版本由 Git 历史保存。
- 学习代码继续独立演进，不直接覆盖为参考答案。
