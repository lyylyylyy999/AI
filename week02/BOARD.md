# 第 2 周学习看板：JSON、HTTP 与 API 基础

## 本周项目

研究摘要结构化提取 CLI：读取摘要文本，调用 DeepSeek API，将结果校验后输出为 UTF-8 JSON。

本周按“本地数据 → HTTP 边界 → 模型 API → CLI 与测试”推进。每张卡验收通过后再进入下一张，不提前堆叠框架或异步代码。

## 完成定义

- 输入支持直接文本或文本文件。
- 使用 `DEEPSEEK_API_KEY`，密钥不进入代码、测试、日志或 Git。
- HTTP 客户端显式配置 timeout。
- 分离 HTTP 响应、模型文本和经过校验的业务数据。
- 对缺少密钥、网络错误、超时、401、429、500、非法 JSON 和字段缺失给出明确错误。
- 自动化测试只使用假 Key 和 Mock，不依赖真实网络。
- Ruff check、Ruff format --check、mypy strict 和 pytest 全部通过。

## 范围控制

本周优先完成一条可靠的同步调用链。不引入异步、Web 框架、数据库、LangChain 或过重的数据模型框架。若时间不足，优先保证数据契约、错误边界和 Mock 测试，不用覆盖率数字替代有效测试。

## 安全约束

- 不读取或打印 `.env` 内容。
- 不在错误信息中回显 Authorization Header 或完整请求。
- 真实 DeepSeek 调用仅作为后续手动冒烟测试；调用前说明目的和预计请求次数。
- 第 1 课完全离线，不发起任何网络请求。
