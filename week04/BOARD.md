# 第 4 周学习看板：研究摘要 CLI 集成与阶段验收

## 本周目标

把前三周的 JSON、校验、HTTP 和 DeepSeek 响应处理组装成可使用、可测试的研究摘要结构化提取 CLI，完成第 1 阶段验收。

## 容量

- 3 个主要实现任务加 1 次阶段复盘，总量控制在 6–9 小时。
- 真实 API 冒烟测试是可选项，不作为自动化质量门。

## 看板

| 卡片 | 目标 | 预计时间 | 状态 | 验收证据 |
|---|---|---:|---|---|
| W4-01 | CLI 文本/文件输入与 UTF-8 JSON 输出 | 60–90 分钟 | 待开始 | CLI 集成测试，无网络 |
| W4-02 | 错误翻译与退出码矩阵 | 60–90 分钟 | 待开始 | 缺 Key、timeout、网络、401、429、500、非法响应 |

| W4-04 | 可选真实 API 冒烟测试 | 15–30 分钟 | 可选 | 调用前确认费用与请求次数，不记录密钥 |
| W4-05 | 阶段 1 复盘、独立题与项目介绍 | 60–90 分钟 | 待开始 | 全量质量门、评分和薄弱点分析 |

## 阶段 1 完成定义

- 输入支持直接文本或 UTF-8 文本文件。
- API Key 只从 `DEEPSEEK_API_KEY` 获取。
- 分离 HTTP response JSON、模型文本和已校验业务数据。
- 输出完整六字段 UTF-8 JSON。
- 自动化测试不依赖真实网络。
- Ruff、mypy strict 和 pytest 全部通过。
- 能在 2 分钟内解释架构、错误边界、测试策略与项目局限。
